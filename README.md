# 📰 Fake News Headline Generator

A simple Python project that generates random and fun fake news headlines using predefined lists of subjects, actions, and objects.

🚀 Features
Generates random headlines using Python
Uses lists and random selection
Supports multiple headline generation at once
Handles invalid input using exception handling

🛠️ Tech Used
Python
random module

▶️ How to Run
Run the Python file
Enter how many headlines you want
View generated headlines
Choose whether to generate more

💡 Example Output
1. Virat Kohli Playing Football on the moon!
2. Kylie Jenner Fighting with President in a Hotel!
